# SecureWatch

SecureWatch is a File Integrity Monitoring System developed using Python and Flask.

## Features

- SHA256 File Hashing
- Real-Time File Monitoring
- File Modification Detection
- File Deletion Detection
- Login Authentication
- Cybersecurity Dashboard
- Live Logs
- Kali Linux Compatible

## Technologies Used

- Python
- Flask
- HTML/CSS
- SHA256
- JSON

## Run Project

python monitor.py
python app.py
python login.py
